# Laboratorio de desarrollo: Python, Django, PostgreSQL e IA

Mi repositorio de estudio para pasar de "hacer andar las cosas con IA" a **entender lo que construyo**.

## Ruta
| Fase | Tema | Proyecto |
|------|------|----------|
| 1 | Python sólido | Ejercicios + mini sistema por consola |
| 2 | Django | Sistema de inmobiliaria desde cero |
| 3 | PostgreSQL | Migrar la inmobiliaria a Postgres |
| 4 | IA | RAG, evaluación y fine-tuning aplicados |

## Cómo estudio cada lección
1. Leo `teoria.md` y pruebo los ejemplos en la terminal.
2. Resuelvo `ejercicios.py` **sin IA** y ejecuto `python ejercicios.py` para verificar.
3. Escribo `notas.md` con lo que entendí, con mis palabras.
4. Le pido a Claude que me corrija y hago commit.
